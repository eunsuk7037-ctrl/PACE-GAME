# SPACE GAME

어둠에 물든 열 개의 행성을 하나씩 되찾는 2D 우주 슈팅 게임이에요. 팀 **YUMM**이 Unity 6로 만들었어요.

## 다운로드

[Releases](../../releases) 페이지에서 `SpaceGame_Windows.zip`을 받아 압축을 풀고 `SpaceGame.exe`를 실행하세요. (Windows 64비트)

## 조작법

| 키 | 동작 |
|---|---|
| W A S D | 우주선 이동 |
| 마우스 클릭 | 메뉴 선택 |
| 아무 키 / 클릭 | 컷신 건너뛰기 |

무기는 자동으로 발사돼요. 플레이어는 움직이면서 피하기만 하면 돼요.

## 게임 소개

- **챕터 10개:** 수성부터 태양까지, 행성 하나가 챕터 하나예요. 챕터마다 그 행성의 보스가 나오고, 보스를 쓰러뜨리면 다음 행성이 열려요.
- **보스전:** 보라색 막에 지배된 행성을 구해요. 태양 챕터에는 최종 보스가 기다려요.
- **성장:** 골드로 무기 4종을 사고 최대 5단계까지 강화해요. 회복 아이템, 챕터별 미션, 레벨업도 있어요.
- **편의 기능:** 계정별 저장, 게스트 이름, 한국어/English, 효과음·음악 볼륨 설정.

## 프로젝트 열기

- Unity **6000.3.18f1**에서 이 폴더를 열면 돼요.
- 처음 열 때 `Library` 폴더를 새로 만드느라 시간이 걸려요.
- 메인 씬: `Assets/Scenes/SampleScene.unity`
